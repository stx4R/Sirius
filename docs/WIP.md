### `bySuit`가 제공하는 것 — §5·§6은 이걸 쓰면 된다

```ts
interface SuitBreakdown {
```

### 2. 드로우 애니메이션

손패 8장이 한꺼번에 나타나면 안 된다.

- 화면 **좌측 밖**에서 시작해 **부채꼴 곡선 궤적**으로 손패 위치까지 비행
- 8장 순차 착지, **stagger 약 60ms**
- 착지 시 살짝 **오버슈트 후 정착** (spring)
- 비행 중 칩끼리 겹쳐 **아치 형태**를 이룬다

### 3. 배치 + 잠금

- 손패 칩 선택 → 위로 떠오르고 테두리 발광
- 보드 빈칸 호버 → 반투명 미리보기
- 배치 → 손패 위치에서 보드 칸으로 이동, 착지에 **바운스**
- 착지 후 칩 상단에 **자물쇠 아이콘 팝인** (고정 표시)
- **자물쇠 픽셀맵을 새로 만들 것** (8×8 또는 12×12) → `src/assets/pixels.ts`

### 5. ★ 정산 애니메이션 — 이번 작업의 핵심

문양 순서(**GAC → IMA → GIN → MIM → ACR**, GDD 3-1 확정 순서)대로 하나씩. 각 문양 차례마다:

1. 해당 문양으로 판정되는 보드 칩 전체에 **골드 링 하이라이트 동시 점등**
2. 발동한 별자리가 있으면 그 **별자리 카드가 튀어오르며 발광**
3. 우측 패널의 해당 **문양 컬럼 숫자가 0 → 목표값 카운트업**
4. 배율이 1.00이 아니면 **배율 숫자도 갱신되며 강조**
5. 하단 **합산식 갱신**
6. **큰 총점 카운트업**

문양 하나당 **약 600ms**, 전체 **3초 내외**.
**속도 조절(1x / 2x / 즉시)과 스킵 버튼 필수.**

### 6. 정산 패널 (우측)

- 상단: **문양 5종 아이콘 가로 배치**
- 각 아이콘 아래 컬럼: 그 문양의 **획득 점수 + ×배율**
- ~~컬럼 아래: 전체 배율~~ → **넣지 않는다** (위 확정 결정 2번)
- 합산식 (예: `30 + 80 + 15 + 0 + 40 = 165`)
- 그 아래: **이번 라운드 누적 점수** — 큰 노란 숫자, 카운트업

문양별 색은 `palette.ts`의 칩 색을 **숫자에도** 적용한다.

### 7. 레이아웃 — 참조 영상과 동일하게

#### 7-1. 손패 아치 조정

참조 영상보다 손패가 많다(8장). 아치 곡률과 간격을 8장 기준으로 다시 잡는다.

- 칩끼리 겹치되 **문양은 전부 식별 가능**할 것
- 호버 시 해당 칩이 떠오르며 **좌우 칩이 살짝 벌어질 것**
- 선택된 칩은 더 크게 떠오르고 발광
