### ★ 별자리 카드가 2×2인 이유 (실측)

GDD 11-5는 카드에서 **이름·조건·배율 텍스트를 뗄 수 없다**고 못박는다. 텍스트 포함 엔트리는
**실측 142px**다.

```
세로 4장: 142×4 + 8×3 = 592  →  y=94 시작 시 686 (캔버스 630 초과)
                                 턴 종료 버튼(y=520)도 관통
2×2:      142×2 + 8   = 292  →  y 94–386, 버튼까지 134px 여유  ✅
```

지시받은 좌표는 카드 이미지(104px)만 계산한 값이었다. 이 때문에 정산 패널이 560 → **584**로
24px 밀렸고 폭은 540 → **516**(컬럼당 100px)이 됐다.

### ★ 상태 텍스트에 exit 애니메이션을 쓰지 말 것

`AnimatePresence mode="wait"`는 **이전 요소의 exit가 끝나야 새 요소를 마운트한다.** 프레임이
한 번 밀리면 새 상태가 아예 마운트되지 않고 낡은 span이 `opacity:0`으로 남아 **상태 줄이 통째로
사라진다.** 실제로 재현했다. 상태 텍스트는 사양상 상시 표시이므로 지금은 애니메이션 없이 렌더한다.
ORION 말풍선도 같은 이유로 `mode="wait"`를 버리고 **y만 움직이고 opacity는 건드리지 않는다** —
프레임이 밀려도 글자는 읽힌다.

### 확정된 결정 (다시 묻지 말 것)

1. **core breakdown = 승인됨.** `cells`까지 반영 완료.
2. **"전체 배율" 칸은 넣지 않는다.** GDD 5-2는 배율을 라인 단위로만 스택한다.
3. **문양별 "×배율"도 하나로 합치지 않는다.** 같은 이유다 — 한 문양에 ×2.5 라인과
   ×1.2 라인이 동시에 있으면 대표값이 존재하지 않는다. **발동한 라인의 배율을 그대로 나열**한다.
4. **`ORION'S WAGER` 명칭 유지.** **иєвυℓα 표기 그대로 노출.**
5. **ORION 대사 RNG는 `game.rng`와 분리한다.** `mulberry32(seed ^ 0x5ee0)`.
   게임 RNG를 쓰면 대사 뽑기가 덱·떠돌이 굴림을 소비해 같은 시드가 같은 판을 재현하지 못한다.
6. **`dialogue.ts`는 `src/ui/`에 둔다** (UI 한국어 텍스트). 따라서 **store는 이걸 import하지 않는다** —
   store→ui는 역방향이다. store는 `seed`만 노출하고, `ui/Orion.tsx`의 `useOrion`이 RNG를 쥔다.
7. **레이아웃은 고정 캔버스다.** 유동 웹 레이아웃으로 되돌리지 않는다 (GDD 11-10).
   좌표는 `ui/Canvas.tsx`의 `LAYOUT` 하나가 정본이고, GDD 11-10 표가 그 사본이다.
8. **배율은 정수 내림이다.** 소수배로 그리면 32×32 칩이 픽셀 경계에 걸쳐 도트 격자가 무너진다
   (CLAUDE.md §7). 캔버스보다 작은 창에서만 예외로 소수배를 쓴다.
